# プラットフォームごとの違い

FUKASIS は 4 つの形で使えます。**撮影できるのは Android と iPhone のアプリだけ**で、web 版と CLI 版は、撮ったデータを PC で処理するためのものです。
スペクトルの計算結果は 4 つとも一致するようにしてあります。

この文書は 2026-10-10 時点の内容です。機能を足したら、ここの表も直してください。

## 全体像

| | Android アプリ | iPhone アプリ | web 版 | CLI 版 |
|---|---|---|---|---|
| 位置づけ | 本体。撮影から出力まで | Android 版の移植 | PC で画像を見ながら処理 | まとめて処理・スクリプト用 |
| 場所 | `app/` | `ios/` | `web/` | `cli/` |
| 言語 | Java + C++ | Swift + C++ | JavaScript | Rust |
| 入手方法 | APK | 自分でビルド | URL を開く | npm / cargo / 実行ファイル |
| 対応環境 | Android 10 以上 | iOS 16 以上 | ブラウザ | 38 機種 |
| 画面の言語 | 日本語・英語 | 日本語 (一部英語) | 日本語・英語 | 日本語のみ |
| 実機での確認 | していない (CI のみ) | していない (ビルドのみ) | サンプルデータで確認 | 3 つの OS でテスト |

## できること

| 機能 | Android | iPhone | web | CLI |
|---|---|---|---|---|
| 撮影 (RAW の積算) | ✓ | ✓ | — | — |
| 白飛びチェック | ✓ | — | — | — |
| ダーク減算 | ✓ | ✓ | ✓ | ✓ |
| 波長校正 | ✓ | ✓ | ✓ | ✓ |
| スペクトル出力 (csv) | ✓ | ✓ | ✓ | ✓ |
| グラフ表示 | ✓ | ✓ | ✓ | ✓ (SVG) |
| 機種設定 (端末プロファイル) | ✓ | ✓ | — | 一部 |

### 撮影

- **Android**: 露出・ISO・ピントを手動で設定し、RAW を積算します。各フレームの DNG も保存します。
  撮影前の試し撮りと撮影中の両方で白飛びを調べます。
- **iPhone**: 同じ流れですが、**1 枚の露出時間に上限があります** (機種によって 1 秒程度まで)。暗い天体は枚数で補います。
  白飛びチェックはありません。詳しくは [porting.md](./porting.md) を参照してください。

### 波長校正

| | Android | iPhone | web | CLI |
|---|---|---|---|---|
| 輝線の本数 | 4 本 + 任意 2 本 | 4 本 | 何本でも | 何本でも |
| 位置の合わせ方 | スライダー | スライダー | ドラッグ・クリック・数値 | 数値を指定 |
| 自動で輝線を探す | ✓ (AUTO) | ✓ (AUTO) | 候補を表示、山へ寄せる | 候補を表示 (`info`) |
| 出力範囲の事前確認 | 保存時に通知 | — | 常に表示 | `calib --check` |
| 参照線 (既知の輝線の位置) | — | — | ✓ | — |
| 参照データのグラフ | — | — | ✓ | — |
| 線ごとの当てはめとの差 | — | — | ✓ | ✓ |

太陽光で校正する用途 (参照データ、フラウンホーファー線) は、web 版だけにあります。

どれで作った校正データも同じ形式 (1 行目が 0次光からの距離、2 行目が波長) なので、互いに読めます。
ただし iPhone 版と、追加の輝線を使わない Android 版が書くのは 4 列です。

## 計算

**スペクトルの値は 4 つとも一致します。** ただし仕組みは 2 通りです。

- **Android と iPhone** は、同じ C++ のコード (`core/Sources/FukasisCoreC/`) をそのまま使っています。
- **web と CLI** は、同じ計算を JavaScript (`web/js/core.js`) と Rust (`cli/src/`) で書き直したものです。
  C++ の出力を正解データ (`testdata/`) として、一致することをテストで確かめています。

計算を変えるときは、C++ を直し、正解データを作り直し ([testdata/README.md](../testdata/README.md))、web と CLI を合わせる、という順になります。

自動校正 (輝線を探して対応づける処理) は Android (`SpectrumCalibrator.java`) と iPhone (`SpectrumCalibrator.swift`) に同じものが 2 つあります。
波長校正の当てはめと出力範囲の計算は、C++ のほかに Java (`CalibrationValidator.java`)、Rust、JavaScript にもあります。片方を直したら、ほかも直します。

一致しないのは次の 2 点です。

- **「感度校正をしない」は web と CLI にしかありません。** アプリにこの出力は無いので、比べる相手がありません。
- **読める画像の形式が違います。** web と CLI は、アプリが書き出す形式の TIFF (無圧縮・ストリップ形式) だけを読みます。圧縮された TIFF は読めません。

## 配布と更新

| | 配布先 | 更新の反映 |
|---|---|---|
| Android | APK ([legrs の Releases](https://github.com/legrs/fukasis/releases)) | 新しい APK を作って配る必要がある |
| iPhone | なし (Xcode でビルド。[porting.md](./porting.md)) | 各自でビルドし直す |
| web | [公開ページ](https://igarinpiano.github.io/fukasis/)、[GitHub Releases](https://github.com/igarinpiano/fukasis/releases) の zip | `release` に push すると自動 |
| CLI | [npm](https://www.npmjs.com/package/fukasis)、[crates.io](https://crates.io/crates/fukasis)、[GitHub Releases](https://github.com/igarinpiano/fukasis/releases) | バージョンを上げて公開 ([releasing.md](./releasing.md)) |

## いまの状態 (2026-10-10 時点)

- **配布されている APK は古いままです。** legrs の Releases にあるのは v1.1.0 で、そのあとの変更
  (計算の修正、出力範囲を波長で決める、白飛びチェック、日英切替、機種設定など) は入っていません。
  新しいアプリを使うには、PR がマージされたうえで APK を作り直す必要があります。
- **そのため、「配布中のアプリ」と「web / CLI」では出力値が違います。** web と CLI は修正後の計算に合わせてあるためです。
- **iPhone 版は、ビルドが通ることまでしか確かめていません。** 実機での撮影は未確認です。
  Android 版にある白飛びチェック、追加の校正点、日英切替も入っていません。
- **Android の新しい機能も、実機では動かしていません。** ビルド・単体テスト・lint が通ることまでの確認です。
- **Android で英語に切り替えても、機種設定まわりの文言は日本語のままです。**
- **web と CLI は、実機で撮った画像ではまだ確かめていません。** 合成したサンプルデータでの確認です。
